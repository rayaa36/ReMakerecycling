# ReMake

A web app that turns everyday waste into something useful — with step-by-step guides and real countdown timers.

Built for GenHacks 2026.

## What it does
Pick from 4 upcycling projects (plastic bottle vase, used cooking oil candle, bottle cap keychain, compost) and follow interactive instructions with a built-in checklist and timer.

## Tech
HTML, CSS, JavaScript (vanilla) — no backend, no dependencies.
